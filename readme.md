Jéssica está desenvolvendo um sistema de cadastro para novos colaboradores das Lojas Brincos e Companhia. A chefia definiu as informações que deverão ser coletadas e solicitou que, após o envio, o sistema apresente os dados cadastrados em uma página de confirmação.

Sua Tarefa:

Você deverá desenvolver dois arquivos:

Desenvolva dois arquivos:

cadastro.html, contendo o formulário;

processaCadastro.php, responsável por receber, armazenar e apresentar os dados enviados.
Requisitos obrigatórios:
O formulário deve conter os seguintes campos:
nome completo;
idade;
profissão;
salário pretendido;
experiência anterior, utilizando um campo de texto longo.
Os nomes dos campos (atributos "name") devem ser criados por você.

coloque os names incluindo números no nome.

O arquivo PHP deverá:

Armazenar todos os dados em variáveis.
Exibir as informações uma por linha.
Gerar uma mensagem personalizada ao final.
Utilize o método POST para o envio dos dados no formulário.

Requisitos do arquivo PHP:

O arquivo deverá:

receber todos os dados enviados pelo formulário;
armazenar cada informação em uma variável;
apresentar cada informação em uma linha;
utilizar elementos HTML para organizar a resposta;
exibir uma mensagem personalizada utilizando, obrigatoriamente, o nome, a profissão e a experiência informados;
apresentar um link ou botão para retornar ao formulário.
Importante:

Você pode usar W3.CSS para estilizar, mas a parte lógica é prioritária.
Evite copiar código pronto: o foco é mostrar sua compreensão da lógica de programação.
Ao utilizar IA adicione:

o prompt utilizado;
a resposta recebida;
o que foi aproveitado;
qual alteração foi realizada por decisão própria.
Não deverá ser aceito apenas o código produzido integralmente pela ferramenta sem adaptação, testes e explicação.

Formato de entrega

Enviar todos os arquivos produzidos (HTML, PHP, CSS)
Enviar documento em PDF contendo:
captura de tela do formulário no Navegador;
captura de tela do processamento no Navegador;
descrição de um erro, dificuldade ou ajuste realizado durante o desenvolvimento.
Prints dos prompts e respostas da IA, quando utilizado.
Formato de entrega

Publicar o projeto no seu perfil no GIT e enviar o link.
 

Critérios de Avaliação

Clareza do código: indentação, comentários e organização.
Funcionamento: os arquivos funcionam corretamente.
Personalização da mensagem: o sistema mostra uma mensagem adequada aos dados inseridos.
Organização do formulário: campos bem distribuídos, usabilidade adequada.
Profundidade na reflexão: resposta reflexiva e coerente às perguntas propostas.
Criatividade: soluções originais, apresentação diferenciada.
Importante: O professor poderá anular a atividade caso identifique "copia/cola" na integra de Inteligência Artificial.
